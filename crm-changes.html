Deal Team (replaces fixed champion / economic buyer)
Flexible list. Each person gets one or more role tags: Champion · Economic Buyer · Budget Influencer · Technical Gatekeeper. Same person can hold multiple roles. Add / remove inline.

Free multi-tag chips. Comma-separated input. Color-coded. Persisted to local DB. Visible on deal cards in the list view.
◷
Activity Log (own table, not embedded in deal)
Log any interaction: Email · Call · Teams Call · Meeting · Demo · LinkedIn · Site Visit · Conference · Other. Each entry: type + direction (Inbound / Outbound / Internal) + date + notes. Links to Company + Contact + Deal IDs. Will be auto-populated by email/Teams agent in Phase 2.
✎
Notes
Quick timestamped notes. Each note: body + author name + created_at. Author field defaults to Vatsal but is editable per note.
☰
Description
Deal description pulled from HubSpot. Read-only (HubSpot is source of truth).
✉
Email History
Last 20 emails linked to this deal via HubSpot. Subject + date + body preview.

Recommendation Engine

Rule Logic

Fires on every deal open. Rule-based today. Feedback loop (thumbs up/down) will train it to Nikhil's judgment over time — Phase 3.

Stage match
→ Stage-specific next action. E.g. "App Note Requested" → "Follow up on pending app note — check if customer has questions or blockers."
Stale > 14 days
! "No activity in N days — send a touchpoint or update deal status."
Close date ≤ 14 days
! "Close date in N days — prioritize this deal."
Close date passed
! "Close date passed N days ago — update expected close or reassess deal."
No Champion
(post initial contact)
? "Identify and document a champion at the customer's organization." Triggered via Deal Team — if no person has Champion role tag.
No Economic Buyer
(proposal stage+)
? "Confirm economic buyer — ensure proposal reaches the decision-maker."
All clear
✓ "Deal is on track — no immediate actions needed."

Email Auto-fill (Activity Log)

HubSpot Write-back (Notes + Activities)

Write deal_notes and activity_log back to HubSpot via Engagements API. Straightforward, deferred for data security phase.

Website Form → HubSpot Contact

Drop HubSpot form embed on CynLr website. 30 minutes when website access is confirmed.
