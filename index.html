Key Changes at a Glance

discovery_batches

Groups every contact from one Claude Code scrape. Cohort tracking, batch approval rates.

contact_reviews

Stores Nikhil's swipe decisions. Separate from contacts — list build filters on yes decisions.

message_templates

Reusable copy with placeholders. Campaigns reference templates, not inline text.

hs_sync_map bridge

Unified local ↔ HubSpot FK table with sync status. Replaces scattered hs_*_id fields.

entry_source on persons

cold / organic / inbound / referral. Separates the two tracks at the data level.

notes + activities + messages merged

All absorbed into activity_log. One unified interaction table, richer queries.
