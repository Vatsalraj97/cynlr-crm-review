Key Changes at a Glance

contact_employments

Job history per person. Enrichment-safe via UNIQUE constraint. Re-enrichment never duplicates.

suppressions

Compliance suppression list. Checked before every send. Blocks sends pre-queue for any suppressed email.

enrichment_jobs

Queued enrichment with retry tracking. No more silent failures — every job has a status and next_retry_at.

deal_stage_transitions

Auto-logged via trigger on deals.stage UPDATE. Pipeline analytics with full history, never manually inserted.

tags → contact_tags

Normalized tag registry replaces comma-separated TEXT blobs. Queryable, no duplicates, no parsing.

contact_emails

Multiple emails per person with primary flag and verified_at. Replaces single email field on persons.

dedup_key on activity_log

UNIQUE constraint prevents duplicate log entries. Idempotent writes — safe to retry without double-logging.

FTS5 full-text search

contacts_fts virtual table. Instant search across name, headline, about, and company. Auto-synced via trigger.

sync_conflicts

HubSpot conflict audit trail. Field-level resolution log for every local vs remote value mismatch.
