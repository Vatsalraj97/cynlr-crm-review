Where these should live
Stay in local CRM only

contact_reviews — pre-outreach review happens before anything goes to HS
suppressions — local enforcement layer, checked before send queue
enrichment_jobs — retry queue is a local infra concern
message_templates — template versioning lives locally
Mirror to HubSpot
campaigns — push campaign name + status to a HS custom deal property so deals show campaign origin

person_lists — mirror to HS static lists for HS-side segmentation and reporting
Use HS natively
